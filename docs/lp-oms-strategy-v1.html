섹터 ETF LP · OMS 호가 전략 v1.1 확정판 — 연속 재고편향 · 파생 구조

2026-09-07 확정 (앵커 RealNav · 자전은 자전방지 플래그 전담 · E/F 제거로 단순화) · 대상: 섹터/테마 ETF 38종 (자기종목 템플릿 — 함수 3개 공용) · 조건변수 A~D, % 단위 부호 입력 (매도 +5bp → 0.05 / 매수 −30bp → −0.30)

1. 전략 전체

재고편향 = RealNav × D × 포지션 ÷ C ÷ 100
매도호가 = RealNav × (100 + A) / 100 − 재고편향
매수호가 = 매도호가 − RealNav × (A − B) / 100
매수를 매도에서 빼서 만든다 → 간격 = (A − B)% 로 산술 고정 (같은 평가 안 크로스 불가)

A·B는 부호 그대로 입력한다 — 매도를 −0.05(NAV 아래)에 벌리는 날도 식이 그대로 작동한다. 유일한 제약은 A > B (간격 양수). 재고 처리는 분기 스위칭이 아니라 연속 편향 — 재고 1주부터 비례해서 양쪽 호가가 같이 밀리고, 한도(C)에서 매도호가가 정확히 정리 레벨 (평균+0.5σ)에 도달하며, 초과분은 더 세게 밀린다. 절벽·깜빡임·이중분기 정지 사고가 구조적으로 없다.

2. 재고별 동작 (예: A=0.084, B=−0.288, σ=0.124%, C=25,000주)

재고 (롱)편향매도호가 위치매수호가 위치상태
0주0+0.084%−0.288%설계 밴드 그대로
3,000 (12%)0.015%+0.069%−0.303%소량도 즉시 비례 정리 — 한도 전에도 항상 정리 가능

37,500 (150%)0.186%−0.102% (= μ)−0.474%초과분 — 더 강한 정리 압력, 절벽 없음

숏 재고는 부호가 뒤집혀 양쪽이 위로 밀린다 (대칭). 마감 전 의무 매수 물량(305540 등)은 이 전략이 플랫된 뒤 15:30 단일가에서 별도로 집행 — 함수와 무관.

3. 자전(自轉) 방어 — 2층

층무엇이 막나어떻게
⓪ 파생 구조같은 평가 안의 크로스매수 = 매도 − RealNav×(A−B)/100. 두 함수가 다른 재고·시세를 읽어도 편향이 소거돼 간격 불변 (증명 §4 하단)
① 자전방지 플래그시차 자전 — NAV 급변 시 새 정정이 아직 안 움직인 옛 반대편 주문과 만나는 경로전 주문에 플래그 활성 (지원 확인됨) → OMS단에서 자기 주문 간 체결 차단
가드(호가1 기준 캡)를 함수에 넣지 않은 이유: NAV 급변으로 호가가 시장을 관통하는 경우, 그 체결가는 상대방 호가 — 즉 내 밴드보다 유리한 가격이라 경제적 손해가 아니다 (싸게 나온 물량을 밴드 한도로 받는 것). 자기 주문 간 충돌만 플래그가 막으면 충분하다. 확인 1건: 플래그의 동작 모드가 "신규 주문 거부"인지 "기존 주문 취소 후 진행"인지 — 어느 쪽이든 치명적이지 않으나 로그 해석에 필요.

자기 크로스 불가 증명 — 매수호가는 항상 매도호가에서 양수(RealNav×(A−B)/100, A>B 전제)를 뺀 값이다. 따라서 매도 − 매수 = RealNav×(A−B)/100 > 0 이 항상 성립한다. 편향(70)은 양쪽에 같은 크기로 들어가 뺄셈에서 소거된다 — 두 함수가 서로 다른 순간의 재고를 읽어도 간격은 흔들리지 않는다.

5. 조건변수 (종목별 · 매일 아침 LENS 엑셀 OMS 시트 A~D 그대로 복사)

변수의미입력 예출처

B매수 % (부호 그대로 — 매수 −30bp면 −0.30)−0.288OMS 시트 B 컬럼

D스큐 강도 = 1σ % (한도 도달 시 매도호가가 정리 레벨에 닿는 값. 키우면 정리 가속)0.124OMS 시트 D 컬럼

6. 정리 모드 — D(스큐) 스텝업

같은 함수 구조에서 D만 키우면 정리 모드가 된다 — 편향이 세져 재고 방향의 호가가 시장 쪽으로 더 깊이 밀리고, 재고가 소진될수록 편향이 자동으로 풀린다. 별도 함수·분기가 필요 없다.

시각D 배수효과 (재고 100% 기준 매도호가 위치)
~14:30×1정리 레벨 μ+0.5σ (평상시)
14:30×2μ−0.5σ — 평균 아래로 밀어 소진 가속
14:45×3μ−1.5σ — 시장 최우선 근처
14:55—잔량만 CD 시분할로 강제 마감 (기존 방식)

운용: 조건변수는 장중 조정이 가능하므로 14:30·14:45에 전 종목 D를 일괄 배수 변경한다. OMS에 시각 필드나 변수 예약 변경 기능이 있으면 함수 자동화 가능 — 있으면 알릴 것. 근거: 정리 물량을 패시브 호가로 소진하는 것이 CD 대비 편측 +15~28bp 우위 (8/28~9/2 채널 분석).
