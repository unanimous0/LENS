섹터 ETF LP · OMS 호가 전략 v1.5 확정판 — 진입 밴드 + 연속 스큐 일원화

2026-09-08 확정 (v1.5: 정리 앵커·임계·분기 전부 폐지 — 재고에 비례하는 연속 스큐 하나) · 함수 3개 (분기 없음) · 매도·매수 전략 독립 할당 · 대상: 섹터/테마 ETF 38종 (자기종목 템플릿) · 조건변수 A~D (A·B·D는 % 부호 입력 — 매도 +5bp → 0.05 / 매수 −30bp → −0.30)

1. 전략 전체 — 식 하나

편향 = RealNav × D × 포지션 ÷ C ÷ 100
매도호가 = RealNav × (100 + A) / 100 − 편향
매수호가 = RealNav × (100 + B) / 100 − 편향
재고 0이면 진입 밴드(A/B), 재고가 커질수록 양쪽이 연속으로 밀린다 — 임계·점프·분기 없음. 같은 편향을 빼므로 어느 재고에서도 매도 − 매수 = (A−B) 고정

D = 1σ가 기준값이다 (엑셀 D 컬럼 = σ결합 그대로). D는 "한도까지 다 찼을 때 총 몇 σ 내려오나"고, 중간 재고는 그 비율만큼만 내려온다:

재고 (한도 C 대비)재고 방향 호가 위치의미
0 (플랫)진입 밴드 μ±1.5σ양쪽 극단에서 대기
~25%밴드 근처 (−0.25σ)소량 — 정리 서두르지 않음, 완만한 스큐만
50%μ±1σ절반 차야 반 시그마 내려옴
100% (한도)μ±0.5σ터치 백테스트 청산 레벨 — 한도 꽉 차야 여기

정리 속도는 D 하나다 — 세게 하려면 키우고, 느리게 하려면 줄인다 (2σ 기본은 실운영 이틀째 "절반도 안 찼는데 정리가 세다"로 1σ로 완화, 2026-09-09). v1.2~v1.4의 정리 앵커(E/F)·시작 임계(G)는 전부 폐지 — 점프 없는 수량 비례 가중이 최종 구조.

3. 함수 코드 (3개 · 분기 없음 · 전 종목 공용 — 자기종목 템플릿)

RealNav는 항상 유효값 전제(확인됨). 문법상 else가 필수라 호가 함수의 else에는 절대 체결되지 않는 안전값(자기 방향 8호가)을 둔다 — 도달 불가 분기.

70. LP_매도호가 — 매도 전략에 할당
if 1>0
then
return [자기종목.RealNav] * (100 + [조건변수.A]) / 100
     - [함수.LP_재고편향.72]
else
return [자기종목.매도8호가]
71. LP_매수호가 — 매수 전략에 할당
if 1>0
then
return [자기종목.RealNav] * (100 + [조건변수.B]) / 100
     - [함수.LP_재고편향.72]
else
return [자기종목.매수8호가]
72. LP_재고편향 — 헬퍼 (70·71 공용)
if 1>0
then
return [자기종목.RealNav] * [조건변수.D]
     * [자기잔고.포지션수량] / [조건변수.C] / 100
else
return 0
자전 방지는 어디 있나 — 두 함수가 같은 편향(72)을 빼는 구조 자체다. 매도 − 매수 = RealNav×(A−B)/100 > 0 이 어느 재고에서도 산술적으로 성립해 겹칠 수 없다 (분기가 없으니 분기 불일치 경로도 없다). 시차 케이스(NAV 급변 직후 새 정정이 옛 반대편 주문과 만나는 경로)는 함수가 자기 주문 가격을 읽을 필드가 없어 함수로는 원리적으로 못 막는다 — 주문 설정의 자전방지 플래그(지원 확인됨)가 전담. 확인 1건: 플래그 동작 모드 (신규 주문 거부 vs 기존 주문 취소 후 진행) — 로그 해석용.

4. 조건변수 (종목별 · A~D 4개)

변수의미입력 예출처
A진입 매도 % (플랫일 때 매도 위치, μ+zσ)0.084OMS 시트 A 컬럼 — 수동 판단 조정 자유 (한쪽만도 OK — 정리에 영향 없음)

D스큐 % = 1σ — 한도 재고에서 호가가 밀리는 총 폭. 키우면 정리 가속0.124OMS 시트 D 컬럼 (= σ결합)

5. 정리 모드 — D 스텝업

평상시 정리는 연속 편향이 상시 수행한다. 마감 전엔 D만 키우면 같은 재고가 더 깊이 밀리고, 소진될수록 자동으로 풀린다.

시각조작효과 (재고 50% 기준 매도호가)
~14:30—μ+1σ (평상시)
14:30D ×2μ+0.5σ — 백테스트 청산 레벨
14:45D ×3μ — 평균만 오면 소진
14:55—잔량만 CD 시분할로 강제 마감 (기존 방식)

운용: 조건변수는 장중 조정이 가능하므로 14:30·14:45에 전 종목 D를 일괄 배수 변경한다. 소량 잔재고는 스텝업으로도 덜 밀리므로 14:55 CD가 최종 안전망. OMS에 시각 필드나 변수 예약 변경 기능이 있으면 함수 자동화 가능 — 있으면 알릴 것. 근거: 정리 물량 패시브 소진이 CD 대비 편측 +15~28bp 우위 (8/28~9/2 채널 분석).

6. 배포 전 체크리스트

#확인방법
1간격 유지 — 매도·매수 두 전략이 같은 시점 재고·RealNav를 읽어 간격이 (A−B)%로 유지되는지소량 운용으로 매도−매수 차이가 항상 RealNav×(A−B)/100인지
2템플릿 스코프 — [자기잔고.포지션수량]이 종목별로 잡히는지 (전략 합산이면 안 됨)두 종목에 붙이고 한쪽만 체결시켜 편향 분리 확인
3스큐 실측 — 1,000주 체결 직후 양쪽 호가가 D×(1,000/C)%만큼 밀리는지소량 1회 체결 후 호가 위치 확인
4자전방지 플래그 모드 — 자전 상황에서 신규 거부인지 / 기존 취소 후 진행인지모의 또는 소량으로 1회 유발해 로그 확인
5조건변수 소수 자리 — 0.084 같은 3자리 소수가 정상 저장되는지변수 입력 화면
68호가 필드 — [자기종목.매도8호가/매수8호가] 필드명 존재 (else 안전값)필드 목록 확인
운영 각주: ① 이력 — v1.1 연속 편향(1σ/한도, 정리 못 미침) → v1.2 정리 앵커 E/F → v1.3 (A+B)/2 복원 → v1.4 F=μ 직접+임계 G → v1.5 앵커·임계 전부 폐지, 연속 편향 D=2σ로 회귀·일원화 (사용자 결정: "임계 말고 수량 비례 가중"). 구 버전 변수 E·F·G는 더 쓰지 않는다. ② VI·단일가 구간에도 함수는 RealNav 기준 값을 반환 — 해당 구간 주문 처리는 OMS 기본 동작. ③ A~D는 매일 엑셀 갱신 — 단일 진실원은 LENS 엑셀 OMS 시트. ④ 알려진 트레이드오프: 부분 재고는 백테스트 청산 레벨(μ+0.5σ)보다 바깥에서 대기하므로 회전이 느리다 — 밴드를 지키는 기회비용 판단(사용자, 2σ→1σ 완화 포함)이 우선. 회전이 아쉬우면 D를 키운다.
