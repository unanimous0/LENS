계기판 (상단 고정)

항목의미
K200F · KQ150F지수선물 실시간 시세 (미니K200 우선, 없으면 K200F 폴백). 헤지 계산의 기준가.
미헤지 델타버킷 노출 + 보유 선물 가치의 합. 초록=미니K200 0.5계약 이내(더 못 줄이는 수준), 주황=1.5계약 이내, 빨강=초과.
버킷 2줄K200/KQ150 버킷별 노출(₩) = Σ(포지션 평가액 × β). 그 옆이 실행 지시: 미니K200 3계약 매도 (보유 0 / 목표 −3) — 이 숫자만 읽고 집행하면 됨.
잔차 / 한도β 헤지로 지워지지 않는 섹터 고유 리스크 추정(Σ|평가액|×잔차변동성). 한도 대비 표시.
호가 z 토글제안 호가 폭의 배수 1.0σ / 1.25σ / 1.5σ / 2.0σ (기본 1.5). 낮출수록 타이트 → 자주 체결, 높일수록 극단만. x 툴팁의 "도달 N일"을 보며 조절.
지평 토글σ선물을 재는 시간 단위 1분/2분/5분 (기본 1분 = 체결→헤지 소요 감각). 길수록 폭이 넓어짐.
체결 입력396500 +5000 @33100 / 헤지는 MK200 -3 @1016.25. A접두·ISIN 코드도 수용. 입력 순간의 iNAV·지수선물가가 진입 기준으로 저장됨.
정리 미리보기전 포지션을 PDF로 종목 분해·넷팅한 주식 바스켓 + 선물 청산 레그. "바스켓 복사"로 OMS에 붙여넣기.

테이블 ② 통계 근거 — "왜 이 호가인가"

컬럼의미산식 / 출처
x매도
x매수		호가를 붙일 bp 폭. 아랫줄 "N일 중 M일" = 최근 캘리브 창에서 장중 괴리가 이 레벨에 닿은 날 수 (체결 가능성). 매도가 0일이면 그 호가는 장식. x = μ괴리 ± z·√(σ괴리² + σ선물²)
μ·σ괴리: 최근 10일 30초봉, 가격 vs 재구성 NAV 괴리의 평균·σ
σ선물: 선물 대비 괴리의 지평(1/2/5분) 변화 σ — 직접 측정
1시간 주기 자동 재계산
선물대비오늘 이 ETF가 선물 대비 몇 bp 아웃/언더퍼폼했나 — 잔차 리스크 감각용, 호가 산식과는 무관ETF 등락률 − (β_K×K200F 등락 + β_Q×KQ150F 등락)
β_K · β_Q이 ETF가 K200/KQ150을 얼마나 따라가나 — 헤지 계약수와 edge 계산의 핵심. PDF 구성(코스피/코스닥 비중)이 여기 반영됨.120일 일봉 2-팩터 회귀 (지수 기준)
R²회귀 설명력. 낮으면 지수선물 헤지 신뢰도가 낮다 → 호가 폭·수량 보수적으로.0~1

행 클릭 (상세 펼침)

패널보는 법
괴리 분포최근 10일 장중 괴리 히스토그램 + 내 x매도/x매수 마커. 내 호가가 분포 어디에 서 있고 얼마나 자주 걸릴지가 그림으로 보임. 포지션이 있으면 마커가 재고 편향만큼 이동(라벨에 −편향 표기).
선물 대비 경로최근 2~3일의 선물 대비 괴리(s) 30초 경로 — 이 섹터가 지수와 얼마나 붙어 다니는지, 최근 틀어지고 있는지.
rolling β60일 이동 β 추이 — 관계가 안정적인지. 출렁이면 헤지 신뢰 하락.
PDF 상위 10구성종목·비중·시장(코스피/코스닥) — β 구성의 근거 확인.
알아둘 것: ① x의 원천인 재구성 NAV는 공식 NAV와 상수 편차(보수·배당 계상)가 있을 수 있음 — 장중 괴리bp 컬럼과 μ를 대조하며 운용 (공식 NAV 적재는 Finance_Data 후속). ② 선물 30초봉이 오후(11:26~)만 있어 σ선물은 오후장 표본 기준. ③ 내부망에서는 지수선물 실시간이 아직 없어 호가·괴리는 뜨지만 계약수 환산·edge·선물대비는 비어 있음.
